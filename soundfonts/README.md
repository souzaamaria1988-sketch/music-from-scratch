# SoundFonts

Coloque seus .sf2 ou .sf3 aqui.

O generate.py usa o primeiro que achar pra renderizar o MIDI gerado em WAV.

Se tiver varios, so o primeiro e usado. Renomeie o que quiser que seja principal.

GitHub limita 100MB/arquivo. Use Git LFS se passar:

    git lfs track "*.sf2"
    git add .gitattributes
